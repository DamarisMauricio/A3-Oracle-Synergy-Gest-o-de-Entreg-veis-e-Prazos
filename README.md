# A3-Oracle-Synergy-Gest-o-de-Entreg-veis-e-Prazos
É um sistema desenvolvido com o objetivo de auxiliar equipes e gestores no controle de entregáveis, atividades e prazos de projetos. A aplicação permite o cadastro de projetos, tarefas e responsáveis, possibilitando o acompanhamento do andamento das atividades em tempo real. 
# Oracle Synergy

Sistema de Gestão de Entregáveis e Prazos desenvolvido em Java.

## Funcionalidades

- Cadastro de tarefas
- Definição de responsáveis
- Controle de status
- Gestão de prazos
- Listagem de entregáveis

## Tecnologias

- Java
- Programação Orientada a Objetos
- ArrayList
